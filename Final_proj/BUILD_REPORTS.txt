SPRING_Proposal.pdf is the canonical course proposal. The four-page
SPRING_Multi_System_Optimizer_Proposal.pdf is a supplementary copy containing
the same two main pages plus a workflow appendix and an ED/NN benchmark appendix.
Both PDFs are generated from the same TeX source. They study strongly correlated
quantum systems, using Ising as entry level and Hubbard or FQHE as an advanced
extension. Existing
Ising/FQHE results are preliminary examples; Hubbard calculations are planned.
The supplementary copy's figures are spring_optimizer_workflow.pdf/png and
nn_ed_proposal_examples.pdf/png. make_optimizer_proposal_figures.py regenerates
both figures and proposal_data.tex from the saved benchmark records; input
hashes are retained in proposal_verified_data.json. It performs no training.
All sources, figures, scripts, validation records and the source archive are
colocated under documents/reports/reference/. The generator resolves benchmark
paths from Final_proj, independently of its new location in reference/.
The database introduction reports present Hamiltonian/configuration counts,
decoded input shapes and saved NN log sizes. The same JSON records the size
inventory and hashes of the audited basis, spectrum and prediction files.

ML_Explanation_Note is a separate three-page attachment showing the input
arrays, scalar energy output, Hamiltonian energy calculation and NN role.
It includes a fully worked three-variable teaching example, exact and sampled
energy evaluation, batch shapes and how optimizers use the shared objective.
Its TeX source is self-contained. SPRING_Proposal_With_ML_Explanation combines
the four-page supplementary copy and this attachment into a seven-page
supplementary reading packet; it is not a separate proposal.
Earlier versions remain in older_documents/ml_explanation_detailed_20261023
and older_documents/ml_explanation_one_page_20261023 under the archive below.

The older reading report's analytical illustration and its generating script
remain next to its TeX file. That illustration evaluates an analytic polynomial;
the modified proposal's NN figures instead use the executed benchmark runs.

To rebuild, start from Final_proj and run latexmk in the reference folder so
the included data and figures resolve:
  cd documents/reports/reference
  latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=/tmp/fqh_report_build 2412_00618_reading_report.tex
  latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=/tmp/spring_optimizer_proposal_build SPRING_Multi_System_Optimizer_Proposal.tex
  latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=/tmp/ml_explanation_note_build ML_Explanation_Note.tex

Build the canonical two-page proposal from the same source, omitting the
appendices (run twice to settle PDF cross-references):
  pdflatex -interaction=nonstopmode -halt-on-error -jobname=SPRING_Proposal -output-directory=/tmp/spring_optimizer_proposal_build '\def\OutlineOnly{1}\input{SPRING_Multi_System_Optimizer_Proposal.tex}'

Inspect the generated PDFs before replacing the retained copies. From the
reference folder, copy the reviewed canonical proposal into its parent folder:
  cp /tmp/spring_optimizer_proposal_build/SPRING_Proposal.pdf ../SPRING_Proposal.pdf
Copy the reviewed supplementary PDFs into reference/:
  cp /tmp/spring_optimizer_proposal_build/SPRING_Multi_System_Optimizer_Proposal.pdf .
  cp /tmp/ml_explanation_note_build/ML_Explanation_Note.pdf .
  cp /tmp/fqh_report_build/2412_00618_reading_report.pdf .

The revised proposal was prepared on 23 October 2026; the detailed reading report remains
